## Claude Cockpit 1.2.0

### Announcement
- **Claude Cockpit becomes "Cockpit for Claude" and is moving to the Mac App Store.**
  This is the last version distributed outside the App Store. It keeps working as
  it is; the app will tell you, through this same update channel, as soon as the
  App Store version is available.

### Changed
- Updates are now checked on `smartcolibri.github.io`, the project's new home
  (the repository moved to the Smart Colibri organisation).
- A dismissible notice on the Overview explains the move.

Nothing else changes: `~/.claude` is still only ever opened for reading.
