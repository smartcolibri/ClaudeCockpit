Support

Cockpit for Claude shows your local Claude Code usage and cost, your sessions, your RTK savings and your skills, agents and commands, in one native Mac app. Requires macOS 14 Sonoma or later.

Contact contact@smartcolibri.fr Please include your macOS version, the app version (Cockpit for Claude › About) and what you expected to see. Never send your transcripts: they may contain private code.

Frequently asked questions

Why does the app ask for access to a folder?

Mac App Store apps are sandboxed: they can only read the folders you allow. On first launch, choose Allow Access to My Home Folder… so the app can read ~/.claude, RTK and your project folders, or allow only ~/.claude. Access is read-only, except for skill transfers you start yourself. You can review or remove permissions in Settings › Access.

My Claude Code folder is not in ~/.claude.

If you set CLAUDE_CONFIG_DIR, choose that folder in Settings › Access, then allow it when asked.

The RTK section says the database is missing.

RTK must be installed and have run at least once. The app looks for history.db in RTK's usual locations. If yours is elsewhere, choose it in Settings › RTK.

Are the costs what I actually pay?

No. Costs are estimated from the tokens recorded in your transcripts, at Anthropic API rates. On a Pro or Max subscription you pay a flat price, so read the figures as the API value of your usage. You can adjust prices and currency in Settings.

Why is "Not enough history to compare" shown?

Claude Code removes old transcripts after about 30 days, and the app only knows what it has scanned since it was installed. Comparisons with a previous period appear once that period is covered.

Sessions are missing or out of date.

The index updates while the app runs. If something looks wrong, use Settings › General › Rebuild Index.

Can I try the app without my own data?

Yes. On the welcome screen, choose Explore with Sample Data. Demo mode uses fictional data and changes nothing on your Mac; leave it with Exit Demo.

Does the app send my data anywhere?

No. It has no network access at all. See the privacy policy.

How do I uninstall it completely?

Move the app to the Trash, then delete ~/Library/Containers/fr.smartcolibri.cockpitforclaude. Your Claude Code files are never touched.

Questions fréquentes

Pourquoi l'app demande-t-elle l'accès à un dossier ?

Les apps du Mac App Store sont isolées (sandbox) : elles ne lisent que les dossiers que vous autorisez. Au premier lancement, choisissez Autoriser l'accès à mon dossier personnel… pour que l'app lise ~/.claude, RTK et vos dossiers de projets, ou n'autorisez que ~/.claude. L'accès est en lecture seule, sauf pour les transferts de skills que vous lancez vous-même. Vous pouvez revoir ou retirer les autorisations dans Réglages › Accès.

Mon dossier Claude Code n'est pas ~/.claude.

Si vous utilisez CLAUDE_CONFIG_DIR, choisissez ce dossier dans Réglages › Accès, puis autorisez-le quand l'app le demande.

La section RTK indique que la base est introuvable.

RTK doit être installé et avoir tourné au moins une fois. L'app cherche history.db aux emplacements habituels de RTK. S'il est ailleurs, choisissez-le dans Réglages › RTK.

Les coûts affichés sont-ils ce que je paie ?

Non. Les coûts sont estimés à partir des tokens enregistrés dans vos transcripts, aux tarifs de l'API Anthropic. Avec un abonnement Pro ou Max, vous payez un forfait : lisez ces chiffres comme la valeur API de votre usage. Tarifs et devise se règlent dans les Réglages.

Pourquoi « Pas assez d'historique pour comparer » ?

Claude Code supprime ses anciens transcripts après une trentaine de jours, et l'app ne connaît que ce qu'elle a lu depuis son installation. Les comparaisons avec la période précédente apparaissent dès que celle-ci est couverte.

Des sessions manquent ou ne sont pas à jour.

L'index se met à jour pendant que l'app tourne. En cas de doute, utilisez Réglages › Général › Reconstruire l'index.

Puis-je essayer l'app sans mes propres données ?

Oui. Sur l'écran d'accueil, choisissez Explorer avec des données d'exemple. Le mode démo utilise des données fictives et ne modifie rien sur votre Mac ; quittez-le avec Quitter la démo.

L'app envoie-t-elle mes données quelque part ?

Non. Elle n'a aucun accès au réseau. Voir la politique de confidentialité.

Comment la désinstaller complètement ?

Mettez l'app à la corbeille, puis supprimez ~/Library/Containers/fr.smartcolibri.cockpitforclaude. Vos fichiers Claude Code ne sont jamais touchés.
